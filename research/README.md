# 研究项目：二战前夕的世界省份划分（1936）

> 状态：**实施中**（2026-10-29 启动，同日确认 D1–D4）· 负责人：hortensia · 产出将驱动 `tools/mapgen` 的下一版

## 1. 问题

现有 `world-1939` 地图由**现代**一级行政区（Natural Earth）切 1938 年国界、再按权重合并/Voronoi 切分得到，问题：

| 问题 | 例子（当前生成结果） |
| :--- | :--- |
| 省份是现代行政区，不像那个年代的地图 | 德国按现代州、波兰按 1999 年后的省切分；地名用现代拼写（Chișinău、Cluj-Napoca） |
| 历史上重要的地区不存在 | 梅梅尔并在柯尼斯堡省里；苏台德区、萨尔、阿尔萨斯-洛林、但泽走廊都不是独立的单元 |
| 归属错误 | 但泽归波兰（实为自由市） |
| 城市省份小到无法点击 | “London”= 伦敦金融城 10 km²，伦敦市区反而在 “Southend-on-Sea” 省里；“Paris”= 75 省 109 km²；直布罗陀 3 km² |
| Voronoi 切分产生几何直线边界 | 西伯利亚、北非、加拿大等大省 |

## 2. 目标

为 **1936 年** 开局设计一套全球约 1000 个省份的划分，要求：

1. **历史性**：省份以 1936 年实际存在的行政单位为基本砖块（德国的普鲁士省/行政区、波兰的省、捷克斯洛伐克的州与区、法国的省、英国的郡……），名称用 1936 年的官方名称。
2. **可玩性**：省份大小在同一地区内大致均衡；最小省份在默认缩放下可点击；大都市按都会区成省（大伦敦、塞纳 + 塞纳-瓦兹 + 塞纳-马恩 = 巴黎地区）。
3. **战略地理**：战间期的争议地区与战争目标是独立的省份（苏台德、梅梅尔、但泽、萨尔、莱茵兰、阿尔萨斯-洛林、波兰走廊、比萨拉比亚、特兰西瓦尼亚、卡累利阿地峡、亚历山大勒塔、满洲各省……），使 1936–1945 年的领土变更都能以“整省转移”表达。
4. **开放数据**：所有几何来源须为开放许可（CC0 / 公有领域 / CC-BY / GPL 兼容），可随模组再分发。
5. **可复现**：全部由脚本 + 人工维护的 CSV 生成，任何人重跑得到同样结果。

非目标：海军、海洋省份；1936 年以外的剧本（但划分要能承载 1936–1945 年的边界变化）。

## 4. 方法与流程

```
research/
  README.md              本文件：章程、进度、决策记录
  notes/                 调研笔记（每个研究问题一份；地区调研放在 notes/regions/）
  scripts/               可复现的调研脚本（普查、抽查、对比）
  data/                  下载的原始数据缓存（不入库，见 .gitignore）
```

1. **数据普查**（R1）：对候选数据源做覆盖度与几何质量检查，脚本放 `scripts/`，结论写 `notes/`。
2. **版图基线**（R2）：列出 1936-01-01 的国家、领土、占领区、战争，并与现有 `tools/mapgen/data/*.csv` 对比，得出需要改动的数据清单。
3. **划分规则**（R3）：先定规则与验收用例，再按地区逐一确定数据层（R4）。
4. **原型**：在 `tools/mapgen` 中实现“历史行政区砖块”管线，先做中欧（德、奥、捷、波、但泽、梅梅尔、立陶宛），用验收用例检查后再推广到全球。
5. **验收**：把验收用例写成生成器的断言（见 partition-principles.md §6），每次生成自动检查。
